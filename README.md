# Web Multimedia Portfolio — Первый шаг в AI

Мой учебный проект по специальности «Информационные системы и программирование» (квалификация: разработчик веб и мультимедийных приложений).

## О проекте
Это базовый фронтенд-каркас (HTML/CSS/JS) + простой Node.js бэкенд. Сейчас проект демонстрирует навыки верстки и работы с веб-технологиями.

**Моя цель:** превратить этот проект в прототип AI-сервиса. Я планирую добавить сюда простую ML-логику (например, анализ текста или генерацию описаний), чтобы показать навыки работы с ИИ.

## Стек технологий
- **Frontend:** HTML5, CSS3, JavaScript.
- **Backend:** Node.js, Express.
- **Инструменты:** Git, npm.
- **Планы:** Python (Pandas, Scikit-learn), FastAPI.

## Как запустить
1. Клонируйте репозиторий.
2. Установите зависимости: `npm install`.
3. Запустите сервер: `node server.js` (или как у тебя назван главный файл).
